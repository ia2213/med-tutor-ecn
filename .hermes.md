# MedTutor ECN — Hermes Context

Medical tutoring app for French ECN/EDN students. Single-page HTML + Python proxy server + OmniRoute local AI.

## Stack

- **Frontend**: Plain HTML/CSS/JS → GitHub Pages (static) / local dev
- **Proxy server**: Python `server.py` on port 8765 (serves frontend + proxies `/api/*`)
- **Backend**: Node.js on port 4000 (NOT in this repo — separate project)
- **AI**: OmniRoute local (port 20128) — `stream: false` required
- **PDF**: pdfjs-dist server-side extraction (Node backend handles this)

## How to Run Locally

```bash
# Terminal 1: Node backend (separate project)
cd /path/to/node-backend && node index.js  # port 4000

# Terminal 2: Python proxy server (this repo)
cd med-tutor-ecn && python3 server.py  # port 8765, serves frontend + proxies /api/*
```

Open http://localhost:8765 in browser.

## GitHub Pages Limitation

GitHub Pages is **static only** — no server-side processing. The chat AI requires:
- OmniRoute running locally (port 20128) — works only from localhost
- OR a deployed backend with API proxy

Current live site (https://ia2213.github.io/med-tutor-ecn/) has UI but chat only works if user runs the local servers.

## Architecture

```
Browser (port 8765 or GitHub Pages)
    │
    ├── GET /           → server.py serves index.html (static)
    ├── GET /api/books  → server.py proxies to Node backend :4000
    ├── POST /api/upload → server.py proxies to Node backend :4000
    ├── DELETE /api/books/:id → server.py proxies to Node backend :4000
    ├── POST /api/chat  → server.py proxies to Node backend :4000
    │
Node Backend (port 4000, separate project)
    ├── PDF extraction (pdfjs-dist)
    ├── Book storage (extracts/*.json)
    └── AI chat via OmniRoute (127.0.0.1:20128)
```

## OmniRoute Integration Rules

1. **Always use `stream: false`** — OmniRoute returns SSE by default, browser fetch can't parse it
2. **Mixed content** — HTTPS pages (GitHub Pages) cannot call `http://127.0.0.1:20128`
3. **Health check**: `curl http://127.0.0.1:20128/v1/models`
4. **Chat endpoint**: `POST http://127.0.0.1:20128/v1/chat/completions`

## Common Pitfalls

1. **SSE parsing error** — OmniRoute returns SSE by default. Always add `"stream": false` to chat requests
2. **Mixed content** — GitHub Pages is HTTPS, cannot call `http://localhost:20128`. Works only from local HTTP server
3. **PDF extraction hangs** — Node backend handles all pages; frontend shows progress bar during upload
4. **server.py must run before frontend** — index.html uses `http://127.0.0.1:8765/api/*` paths
