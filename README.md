## 🔧 Déploiement Vercel

Pour déployer sur Vercel:

2. Cliquez sur votre projet **med-tutor-ecn**
3. **Settings → General**
4. **Root Directory:** changez `med-tutor` en **`/`**
5. **Save** → **Deployments → Redeploy**
