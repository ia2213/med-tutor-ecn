## 🔄 Déployer sur Vercel

1. Allez sur **https://vercel.com/dashboard**
2. Cliquez sur votre projet **med-tutor-ecn**
3. Allez dans **Deployments**
4. Cliquez sur le déploiement échoué → **Redeploy**
5. Ou supprimez le projet et recréez-le

**Root Directory:** laissez **vide** (ou mettez `/`)
