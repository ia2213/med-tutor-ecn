## 🎯 Prochaines étapes

### 1. Déployer sur Vercel (pour le chat IA)

La version GitHub Pages est **statique** (pas de chat IA). Pour le chat complet:

1. Allez sur **https://vercel.com/new**
2. Importez le repository **ia2213/med-tutor-ecn**
3. Cliquez **Deploy**
4. Ajoutez la variable d'environnement:
   - `OPENAI_API_KEY` = votre clé API OpenAI

### 2. Configurer l'API OpenAI

Dans Vercel → Settings → Environment Variables:
```
OPENAI_API_KEY=sk-***
```
